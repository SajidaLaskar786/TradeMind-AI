# TradeMind-AI

## Overview
TradeMind-AI is an AI-powered trading psychology and behavioral coaching system designed to help users understand their trading habits through a paper trading simulator.

## Problem Statement
Traders may make impulsive decisions, overtrade, increase position sizes after losses, or struggle to follow a consistent trading strategy. TradeMind-AI aims to identify potential behavioral patterns and provide explainable, personalized coaching.

## Planned Features
- Paper trading with virtual funds
- Portfolio and trade history tracking
- Behavioral pattern monitoring
- Machine learning-based behavioral classification
- Explainable AI using SHAP
- Real-time behavioral coaching alerts
- Personalized trading psychology reports

## Planned Technology Stack
- Frontend: React
- Backend: FastAPI (Python)
- Database: PostgreSQL
- Machine Learning: scikit-learn
- Explainability: SHAP
- Version Control: Git and GitHub

## Project Status
In development.

## Disclaimer
This project is for educational purposes. Behavioral indicators are estimates, not psychological diagnoses or financial advice.
